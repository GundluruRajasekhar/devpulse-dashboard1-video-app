# DevPulse — Narrated Walkthrough

A single-page, dependency-free explainer for the DevPulse dashboard. Press **Play narration**
and it reads a 10-section walkthrough aloud using your browser's built-in voice (the Web
Speech API) — no audio file, no account, no API key required.

## Why this exists

It's meant to be used two ways:

1. **On its own** — as a quick spoken/readable overview of what DevPulse is and how it's
   built, for anyone reviewing the project who doesn't want to click through the whole app.
2. **As a narration track while recording your demo video** — open this page in one browser
   tab and the live dashboard in another; press Play here, then screen-record yourself
   clicking through the dashboard in the other tab while this narrates in the background.

## Run it

Just open `index.html` in any modern browser (Chrome, Edge, or Safari have the best speech
voice support). No build step, no server required.

To deploy it publicly, upload this folder to a GitHub repo and enable GitHub Pages, exactly
like the rest of the portfolio.
